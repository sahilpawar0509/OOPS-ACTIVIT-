## 📚 Course Roadmap

| Unit | Topic | Main Focus |
|---|---|---|
| **Unit I** | **Fundamentals of Object Oriented Programming** | OOP fundamentals, classes, objects, constructors, static members, inline and friend functions |
| **Unit II** | **Inheritance** | Inheritance, class hierarchies, overriding, virtual base classes and abstract classes |
| **Unit III** | **Polymorphism** | Polymorphism, operator overloading, function overloading and virtual functions |
| **Unit IV** | **Files and Streams** | File handling, streams, text/binary files, file navigation and error handling |
| **Unit V** | **Exception Handling and Templates** | Exception handling, standard/custom exceptions and function/class templates |
| **Unit VI** | **Standard Template Library (STL)** | STL containers, iterators, algorithms, sorting, searching and counting |
